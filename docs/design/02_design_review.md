## 詳細レビュー

### A. 技術選定の妥当性

- **評価: ⭕**
- 指摘事項:
  1. [重大度: Low] `shadcn/ui` のバージョンが `latest` 指定になっている。将来的にブレイキングチェンジが入った場合のリスクがあるため、初期セットアップ時に `package.json` でバージョンを固定すること

### B. アーキテクチャの健全性

- **評価: ⭕**
- 指摘事項:
  1. [重大度: Low] `/api/analyze` はステートレスでクライアントから `question` と `answer` を受け取る設計のため、悪意あるクライアントが任意の文字列を `answer` フィールドに送り込むことができる（プロンプトインジェクションリスク）。MVP 段階では許容範囲だが、実装時に Claude API 呼び出し前に `answer` の文字数上限チェック（例: 2000文字）を追加することを推奨する

### C. API設計の品質

- **評価: ⚠️**
- 指摘事項:
  1. [重大度: Medium] レートリミットが未実装。認証なしのオープン API のため、悪意ある第三者または誤った実装により Claude API が大量呼び出しされ、APIコスト爆発が発生するリスクがある。MVP デプロイ前に最低限の対策（Vercel の IP ベース Rate Limiting または `next-rate-limit` の導入）を検討すること
  2. [重大度: Low] `/api/analyze` のレスポンスから `highlighted_words` を返しているが、これはリクエストのデータをそのまま返しているだけ（エコーバック）。クライアント側で既に保持している情報のため、レスポンスからは省略してシンプル化することを検討できる（現設計でも問題はない）

### D. セキュリティ

- **評価: ⚠️**
- 指摘事項:
  1. [重大度: Medium] APIキー保護は正しく設計されているが、`ANTHROPIC_API_KEY` が `.env.local` に存在することを確認する `.gitignore` の記載が設計書に明示されていない。実装時に `.env.local` を `.gitignore` に追加すること（`create-next-app` のデフォルトで含まれているが、明示的に確認が必要）
  2. [重大度: Low] `extractJson` の正規表現 `/\{[\s\S]*\}/` はグリーディーマッチのため、Claude のレスポンスに複数の JSON オブジェクトが含まれる場合に意図しない範囲を取得する可能性がある。`/\{[\s\S]*?\}/` のレイジーマッチへの変更か、より堅牢な JSON パーサーへの置き換えを検討すること

### E. 実装容易性

- **評価: ⭕**
- 指摘事項:
  1. [重大度: Low] `useTextSelection.ts` フックの実装は SCR-002 のインタラクション設計（「ドラッグ選択→ポップアップ表示→確定でタグ追加」）が複雑なため、実装難易度が高い。テキスト選択ポップアップの表示位置計算（`getBoundingClientRect`）とモバイルでのタッチ対応を早期に実装・検証することを推奨する

## 実装への申し送り事項

1. **APIキー保護の徹底**: `.env.local` を `.gitignore` に含めること（`create-next-app` デフォルトで含まれるが要確認）。`NEXT_PUBLIC_` プレフィックスを `ANTHROPIC_API_KEY` に絶対に付けないこと
2. **レートリミット**: MVP デプロイ時（パブリック公開前）に最低限の対策を入れること。開発・検証フェーズのみならスキップ可
3. **`extractJson` の堅牢化**: Claude API のレスポンスをパースする際は、JSON.parse のエラーを catch して `AI_ERROR` として返す処理を必ず実装すること
4. **`answer` フィールドの上限チェック**: `/api/analyze` の `answer` は 2000 文字以上を 400 エラーで弾くバリデーションを追加推奨
5. **モバイルでのテキスト選択**: iOS Safari では `user-select: text` を CSS で明示しないと選択が無効になるケースがある。早期に実機確認すること
6. **Claude API タイムアウト**: `fetch` に `signal: AbortSignal.timeout(8000)` を設定し、8秒でタイムアウトさせること（要件: 回答5秒・分析3秒 の外側でフェイルセーフ）
